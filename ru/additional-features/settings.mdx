## Обзор

Откройте **Settings** в левом сайдбаре. Настройки разделены на четыре вкладки: **Main**, **Tags**, **RPC** и **Browser**.

## Main

<Frame><img src="/images/atmos_ui/settings/atmos_settings_main.png" alt="Settings — Main tab" /></Frame>

| Настройка | Описание |
|---|---|
| **API key** | Изменить API key, связанный с аккаунтом |
| **Master password** | Изменить master password для шифрования данных приложения |
| **PIN code** | Задать или изменить PIN для подтверждения чувствительных действий: переводов и удаления |
| **Language** | Язык интерфейса |

### Export

Данные можно экспортировать как зашифрованные ZIP-архивы. Доступны три категории:

| Категория | Содержимое |
|---|---|
| **Wallets** | Данные кошельков, включая теги и персонализацию |
| **Accounts** | Данные CEX accounts, включая теги и персонализацию |
| **Software settings** | Настройки RPC, расширения и другие настройки приложения |

### Import

Перетащите ранее экспортированный зашифрованный ZIP-архив или нажмите **Select**.

## Tags

Теги в Oxygen Atmos общие для кошельков, браузерных профилей и exchange accounts. Тег, созданный в одном месте, доступен везде.

<Frame><img src="/images/atmos_ui/settings/atmos_settings_tags.png" alt="Tags management table" /></Frame>

### Таблица тегов

| Колонка | Описание |
|---|---|
| **Name** | Название тега с цветовым индикатором |
| **Count** | Общее число объектов с этим тегом |
| **Browsers** | Чекбокс: тег используется в браузерных профилях |
| **Wallets** | Чекбокс: тег используется в кошельках |
| **Accounts** | Чекбокс: тег используется в exchange accounts |
| **Extensions** | Число профилей с расширениями, назначенными на этот тег |

Таблицу можно фильтровать через **Colors**, **Search** и **Show only unused**.

### Создать тег

Нажмите **Add tag**, введите **name** и выберите **color**.

### Назначить теги

Теги можно назначать в нескольких местах:

- **Wallet manager** — при импорте или редактировании кошелька
- **Browser profiles** — при создании, массовом создании или редактировании профиля
- **Exchange accounts** — при добавлении или редактировании аккаунта

На один объект можно назначить несколько тегов.

### Редактировать и удалить теги

- Нажмите иконку редактирования, чтобы изменить name или color тега. Изменения применятся везде, где используется тег.
- Выберите один или несколько тегов и нажмите **Delete**.

<Warning>
  Удалённые теги автоматически удаляются со всех кошельков, профилей и accounts, где они были назначены.
</Warning>

### Фильтр по тегам

Список кошельков и список профилей поддерживают фильтрацию по тегам:

1. Нажмите **Tags** над списком
2. Выберите один или несколько тегов — останутся только объекты с этими тегами
3. Нажмите **Reset**, чтобы сбросить фильтр

## RPC

Здесь настраиваются RPC endpoints для EVM chains.

| Настройка | Описание |
|---|---|
| **Use global proxy for all RPCs** | Пропускать все RPC requests через один proxy |
| **Use proxy from wallet browser profile** | Использовать proxy браузерного профиля для RPC requests его кошелька |
| **Chain list** | Включать и выключать chains, смотреть статус RPC |

У каждой chain есть health indicator, например **3/3** означает 3 здоровых RPC из 3. Для каждой chain можно добавить до **5 custom RPC endpoints**. Предупреждение `Low active RPCs` появляется, когда часть endpoints не отвечает.

## Browser

Здесь настраиваются браузерные параметры по умолчанию и управление расширениями.

<Frame><img src="/images/atmos_ui/settings/atmos_settings_browser.png" alt="Settings — Browser tab" /></Frame>

### Browser preferences

Профили могут наследовать глобальные настройки браузера или переопределять их в редакторе профиля.

| Настройка | Описание |
|---|---|
| **Search engine** | Search engine по умолчанию для браузерных профилей |
| **Language** | По proxy IP address или вручную, например English United States |
| **App language** | На основе **Language** или отдельно |
| **Timezone** | По proxy IP address |
| **Geolocation** | Ask, Allow или Block, с опциональным proxy IP source |
| **WebRTC** | Disable non-proxied UDP или public interface |
| **GPU spoofing** | Управление GPU metadata и spoofing mode |
| **Noise** | Переключатели Canvas, Audio, Rectangles, WebGL |

Значения по умолчанию:

| Настройка | Значение по умолчанию |
|---|---|
| **Search engine** | DuckDuckGo |
| **Language** | English (United States) |
| **App language** | Based on selected language |
| **Timezone** | Based on proxy IP address |
| **Geolocation** | Ask, based on proxy IP address |
| **WebRTC** | Disable non-proxied UDP |
| **GPU spoofing** | Strict |
| **Noise** | Canvas, Audio и DOM Rectangles включены |

Переопределения профиля используются при генерации fingerprint и запуске браузера.

### Extensions

Oxygen Atmos управляет расширениями для профилей на [Oxidium](/ru/browser-profiles/oxidium). Расширения можно установить глобально, назначить на теги профилей или отключить.

| Действие | Описание |
|---|---|
| **Add** | Установить из Chrome Web Store URL или загрузить CRX/ZIP файл |
| **Update extensions** | Обновить все установленные расширения |
| **Delete** | Удалить расширение |

| Режим загрузки | Описание |
|---|---|
| **Global** | Загружается во все браузерные профили |
| **Tag-based** | Загружается только в профили с хотя бы одним общим тегом с расширением |
| **Disabled** | Не загружается ни в один профиль |

Набор расширений рассчитывается при запуске профиля. После изменения назначения расширений, тегов или файлов расширения перезапустите работающий профиль.

<Info>
  **Rabby Wallet** — встроенное расширение для работы с кошельками. Private keys остаются внутри Oxygen Atmos и не передаются в браузерную среду.
</Info>
