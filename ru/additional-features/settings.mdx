## Обзор

Откройте **Settings** в левом меню. Настройки разделены на вкладки **Main** и **Connection**.

## Main

<Frame><img src="/images/atmos_ui/settings/atmos_settings_main_v040.png" alt="Вкладка Main" /></Frame>

| Настройка | Описание |
|---|---|
| **API Key** | Заменить API key Oxygen Atmos |
| **Master Password** | Изменить пароль локального vault |
| **PIN code** | Задать PIN для чувствительных действий |
| **Language** | Изменить язык интерфейса |

### Экспорт и импорт

В ZIP можно экспортировать **Wallets**, **Accounts** и **Software settings**. Включите **Set encryption password**, чтобы защитить архив паролем.

Перетащите ZIP в область **Import files** или нажмите **Select**. Файл обрабатывается локально и не загружается на сервер.

## Connection

Используйте **Settings → Connection**, если доступ к Oxygen или внешним ресурсам ограничен вашей сетью.

<Frame><img src="/images/atmos_ui/settings/atmos_settings_connection.png" alt="Вкладка Connection" /></Frame>

Выберите **System proxy** или добавьте **Custom proxy**. В Advanced settings маршрут настраивается отдельно:

| Раздел | Поведение |
|---|---|
| **Oxygen API** | Login, subscription, token lists, browser components и обновления используют выбранный маршрут |
| **Wallet RPC** | Прокси кошелька или связанного профиля имеет приоритет |
| **Portfolio data** | Балансы, portfolio и token data используют выбранный маршрут |
| **CEX accounts** | Прокси самого CEX-аккаунта всегда имеет приоритет |
| **Browser profiles** | Всегда используют прокси, сохранённый в профиле |

<Note>
  Connection не заменяет прокси браузерных профилей и не изменяет их трафик.
</Note>
