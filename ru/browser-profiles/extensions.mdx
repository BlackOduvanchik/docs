## Обзор

Откройте **Browser → Extensions**, чтобы управлять расширениями профилей [Oxidium](/ru/browser-profiles/oxidium).

<Frame><img src="/images/atmos_ui/browser/atmos_browser_extensions.png" alt="Менеджер расширений" /></Frame>

Список показывает название, версию, состояние и режим загрузки. Используйте **Search** и фильтр **Tags**.

## Добавить расширение

1. Нажмите **Add**.
2. Выберите **Upload file** или **URL address**.
3. Для URL вставьте ссылку из Chrome Web Store и нажмите **Load**.
4. Включите расширение глобально или назначьте теги профилей.

| Режим | Поведение |
|---|---|
| **Global** | Загружается во всех профилях |
| **Tag-based** | Загружается только в профилях с общим тегом |
| **Disabled** | Остаётся установленным, но не загружается |

Нажмите **Update extensions**, чтобы обновить установленные расширения. После изменения файлов, тегов или режима перезапустите работающие профили.
