## Обзор

Secure notes — приватные заметки, прикреплённые к браузерному профилю. Используйте их для информации, которая должна оставаться рядом с профилем: детали процесса, напоминания по аккаунту или рабочий контекст.

Secure notes остаются в Oxygen Atmos. Они не инжектятся в сайты и не передаются в запущенный браузер.

## Хранение

Secure notes хранятся локально и шифруются.

## Редактирование заметок

Заметки можно редактировать из:

- окна создания или редактирования профиля
- действия secure notes в таблице профилей

## Примеры использования

| Сценарий | Пример заметки |
|---|---|
| **Рабочий контекст** | `Warmup completed — ready for marketplace flow` |
| **Трекинг кампании** | `Lighter Regional Competition — started 2026-01-15` |
| **Статус** | `Proxy changed on 2026-02-01` |
| **Инструкция** | `Keep this profile on the current browser version` |
