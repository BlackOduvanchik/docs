## Что такое браузерный профиль

Браузерный профиль — это сохранённая браузерная идентичность в Oxygen Atmos. Профили разделяют аккаунты, сессии, прокси, кошельки, цифровые отпечатки, cookies, local storage, расширения, закладки и настройки браузера.

Oxygen Atmos хранит и применяет конфигурацию профиля. [Oxidium](/ru/browser-profiles/oxidium) — ядро, совместимое с Chromium, которое открывается при запуске профиля.

[Закладки](/ru/browser-profiles/bookmarks-manager) можно назначить всем профилям или отдельным группам профилей через теги.

## Таблица профилей

На странице Browser отображается информация для ежедневной работы:

| Колонка | Описание |
|---|---|
| **Alias** | Имя профиля в таблице и в браузерном окне |
| **Fingerprint** | Версия браузера и label отпечатка |
| **Tags** | Теги для фильтрации и загрузки расширений |
| **Proxy** | Назначенный proxy IP или статус отсутствующего proxy |
| **Last launch** | Последний запуск профиля |
| **Actions** | Запуск, фокус, редактирование и другие действия |

Поиск работает по alias, адресу связанного кошелька, версии браузера, fingerprint label, proxy URL или proxy IP. Чтобы показать группу профилей, нажмите на тег или используйте фильтр **Tags**.

## Действия с профилем

Основные действия:

- запустить закрытый профиль
- сфокусировать уже запущенный профиль
- закрыть запущенный профиль
- изменить настройки профиля
- изменить связанные кошельки
- изменить теги
- изменить proxy
- открыть secure notes
- удалить профиль

Выбранные профили также можно обрабатывать массово: запускать, закрывать, менять теги, переименовывать или удалять.

## Компоненты отпечатка

Каждый профиль использует согласованный набор браузерных параметров:

| Параметр | Описание |
|---|---|
| **Версия браузера** | Версия [Oxidium](/ru/browser-profiles/oxidium), которая в интерфейсе показывается как Chrome major version |
| **User-Agent** | Строка идентификации браузера и OS |
| **Client Hints** | Chromium Client Hints в headers и JavaScript |
| **Screen resolution** | Размеры экрана |
| **Platform** | Идентификатор OS, например Windows 10.0 |
| **Language** | Язык и locale браузера |
| **Timezone** | Часовой пояс |
| **Geolocation** | Режим доступа и источник геолокации |
| **WebRTC** | Политика сетевого раскрытия |
| **Canvas** | Noise для Canvas |
| **Audio** | Noise для AudioContext |
| **Rectangles** | Noise для DOM Rectangles |
| **WebGL** | GPU metadata и поведение рендера |

<Info>
  Fingerprint генерируется до сохранения профиля. Предпросмотр отражает выбранную версию браузера и настройки браузера.
</Info>

## Статусы профиля

| Статус | Описание |
|---|---|
| **Running** | Браузерное окно сейчас открыто |
| **Not used** | Браузер закрыт, данные сохранены |

## Создание профиля

<Steps>
  <Step title="Нажмите New Profile">
    Нажмите **New Profile** в правом верхнем углу.
  </Step>
  <Step title="Задайте идентичность профиля">
    Введите alias и выберите или создайте теги. Теги помогают фильтровать профили и управлять тем, какие расширения будут загружаться.
  </Step>
  <Step title="Свяжите кошельки">
    Выберите кошельки, если профилю нужна wallet integration. Встроенное расширение Rabby даёт браузерный интерфейс для работы с кошельком.
  </Step>
  <Step title="Выберите версию браузера">
    Выберите версию браузера. Включите **Keep up to date**, если хотите, чтобы Oxygen Atmos мог переносить профиль на одну из последних поддерживаемых версий.
  </Step>
  <Step title="Проверьте fingerprint">
    Проверьте предпросмотр отпечатка. Он включает user agent, platform, language, app language, timezone, geolocation, WebRTC, WebGL и noise settings.

    <Frame><img src="/images/atmos_ui/browser/atmos_browser_new_profile.png" alt="Create new profile with fingerprint preview" /></Frame>
  </Step>
  <Step title="Добавьте proxy">
    Если профилю нужна отдельная сетевая локация, добавьте proxy. Поддерживаются **HTTP** и **SOCKS5**.

    Форматы proxy:

    ```text
    protocol://host:port:user:pass
    protocol://user:pass@host:port
    ```
  </Step>
  <Step title="Добавьте cookies или social tokens">
    Добавьте cookies, X.com tokens или Discord tokens, если их нужно применить при следующем запуске браузера.
  </Step>
  <Step title="Проверьте настройки браузера">
    Используйте глобальные настройки браузера или задайте переопределения для конкретного профиля: search engine, language, timezone, geolocation, WebRTC policy, GPU spoofing mode или noise settings.
  </Step>
  <Step title="Сохраните профиль">
    Нажмите **Save profile**. Чтобы запустить браузер, нажмите на строку профиля.
  </Step>
</Steps>

## Редактирование профиля

После создания можно менять настройки профиля. Некоторые изменения применяются к сохранённым данным сразу, а параметры, связанные с запуском браузера, обычно требуют закрыть и заново запустить профиль.

В режиме редактирования нельзя понизить версию браузера: можно оставить текущую версию или выбрать более новую.

## Кошельки в профилях

У каждого профиля может быть один main wallet на каждый тип кошелька. Main wallet должен существовать в Oxygen Atmos, иметь private key и не быть main wallet в другом профиле.

Также можно добавить дополнительные кошельки. Для дополнительного кошелька нужен main wallet того же типа. Если main wallet удалить, вторичные кошельки этого типа тоже будут удалены из профиля.

При запуске профиля связанные кошельки становятся доступны для работы с кошельками в браузере. Private keys остаются внутри Oxygen Atmos и не передаются в браузерную среду.

## Proxy settings

У каждого профиля свой proxy. Поддерживаются **HTTP** и **SOCKS5**.

Чтобы изменить proxy, откройте редактор профиля и обновите proxy fields.

Если proxy настроен, Oxygen Atmos проверяет его работоспособность и сохраняет доступные данные о локации, например страну и IP.

HTTP- и SOCKS5-прокси можно использовать независимо от поддержки UDP. Если прокси поддерживает UDP, Atmos отправляет через него WebRTC, QUIC и HTTP/3. Если UDP нельзя проксировать, политика **Block unproxied UDP** блокирует этот трафик и не допускает прямого соединения с раскрытием реального IP. TCP-трафик продолжает работать через настроенный прокси.

## Корзина и восстановление

Удаление профиля перемещает его в корзину. В разделе **Browser > Trash** профиль можно восстановить или удалить навсегда.

## Лимит профилей

Количество доступных профилей зависит от текущего membership. Профили сверх лимита помечаются как excessive и не могут нормально использоваться, пока лимит не будет восстановлен.
