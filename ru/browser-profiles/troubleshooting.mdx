Используйте эту страницу, когда браузерный профиль не создаётся, не запускается, не импортируется или работает не так, как ожидается.

## Нет доступного fingerprint

Генерация fingerprint может не пройти, если нет подходящего отпечатка для выбранной версии браузера, platform, architecture и GPU renderer.

Если интерфейс предлагает повторную генерацию без GPU renderer matching, попробуйте этот вариант.

## Proxy check не проходит

Проверьте:

- host и port указаны правильно
- username и password указаны правильно
- proxy-сервер доступен
- текущая сеть может подключиться к proxy
- proxy поддерживает HTTP или SOCKS5

Если в proxy не указан протокол, Oxygen Atmos во время импорта попробует определить, работает ли он как HTTP или SOCKS5.

## Кошелёк не привязывается

Main wallet должен:

- существовать в Oxygen Atmos
- иметь private key
- не использоваться как main wallet в другом профиле

Read-only wallets нельзя использовать как основные браузерные кошельки.

## Cookies не появляются

Импортированные cookies применяются при следующем запуске профиля. Если профиль уже был запущен, закройте и откройте его снова.

Также проверьте domain, path, expiry и secure attributes у cookie.

## X.com или Discord token не применяется

X.com token импортируется как cookie `auth_token` для `.x.com`.

Discord token импортируется в local storage для:

```text
https://discord.com/
```

Если token был добавлен, когда профиль уже работал, закройте и запустите профиль заново.

## Расширение не загружается

Проверьте:

- расширение включено
- оно global или имеет общий тег с профилем
- профиль был перезапущен после изменения расширений
- package расширения валиден

Набор расширений рассчитывается при запуске профиля на [Oxidium](/ru/browser-profiles/oxidium).
