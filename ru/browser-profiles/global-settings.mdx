## Обзор

Откройте **Browser → Global settings**, чтобы задать настройки по умолчанию для новых профилей. В редакторе профиля их можно переопределить.

## Стартовые вкладки

| Режим | Поведение |
|---|---|
| **New** | Открывать новую вкладку |
| **Session** | Восстанавливать вкладки сохранённой сессии |
| **List** | Открывать заданный список URL |

## Язык и местоположение

Здесь задаются **Search engine**, **Language**, **App language**, **Timezone** и **Geolocation**. Язык, часовой пояс и геолокация могут определяться по IP-адресу прокси. Согласуйте их со страной прокси, чтобы сохранить целостный fingerprint.

## WebRTC и защита UDP

Политика **Block unproxied UDP** разрешает UDP только тогда, когда Atmos может отправить его через прокси профиля. Это относится к WebRTC, QUIC и HTTP/3.

- Если прокси поддерживает UDP, Atmos отправляет UDP-трафик через него.
- Если UDP нельзя проксировать, Atmos блокирует его.
- Прямое UDP-соединение в обход прокси не допускается и не раскрывает реальный IP.
- Прокси без UDP продолжает работать для TCP-трафика.

<Warning>
  **Public Interface** может раскрывать данные прямого сетевого интерфейса. Для защиты реального IP используйте **Block unproxied UDP**.
</Warning>

## GPU spoofing и Noise

Доступны режимы GPU: **Strict**, **Compatibility**, **Vendor** и **Disabled**. Noise можно отдельно включить для **Canvas**, **Audio** и **Rectangles**. Текущее состояние отображается в preview профиля.
