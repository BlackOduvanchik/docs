## Создать запланированную задачу

Задачи создаются из [модуля переводов](/ru/transfers/about-transfers): CEX withdrawal или wallet withdrawal.

<Steps>
  <Step title="Настройте перевод">
    Перейдите в **Transfers** в левом сайдбаре и задайте параметры вывода.
  </Step>
  <Step title="Проверьте Preview">
    Нажмите **Preview**, чтобы проверить операцию.
  </Step>
  <Step title="Отложите запуск">
    Нажмите **Postpone** вместо **Launch**.
  </Step>
  <Step title="Задайте расписание">
    Выберите **date and time** для выполнения.

    <Warning>
      Устройство и Oxygen Atmos должны оставаться запущенными, чтобы задача выполнилась в выбранное время.
    </Warning>
  </Step>
  <Step title="Подтвердите">
    Задача появится во вкладке **Scheduled** в Task manager.
  </Step>
</Steps>

## Редактировать запланированную задачу

Во вкладке **Scheduled** нажмите **Open** на нужной задаче, чтобы посмотреть и изменить её. Изменения сохраняются автоматически, когда вы закрываете окно редактирования.

<Frame><img src="/images/atmos_ui/task_manager/atmos_task_manager_tasks_edit_menu.png" alt="Task editing menu with numbered elements" /></Frame>

## Элементы меню редактирования

| # | Элемент | Описание |
|---|---|---|
| 1 | **Scheduled** | Дата и время запуска задачи |
| 2 | **Logs** | Общий лог задачи |
| 3 | **Config** | Workers, delays, retries; недоступно для редактирования во время выполнения задачи |
| 4 | **Action row** | Информация о действии для конкретного кошелька |
| 5 | **Token withdrawal amount** | Сумма вывода на кошелёк; недоступно для редактирования во время выполнения задачи |
| 6 | **Status** | Текущий статус действия |
| 7 | **Wallets** | Прогресс по завершённым кошелькам |
| 8 | **Withdrawal amount** | Общая сумма вывода по всем кошелькам |
| 9 | **Fee** | Общая комиссия по всем кошелькам |
| 10 | **Processing time** | Общее время выполнения |
| 11 | **Use as template** | Меню копирования: use as template, copy all wallets или copy wallets with errors |
| 12 | **Postpone** | Изменить дату и время запуска |
| 13 | **Cancel** | Отменить задачу |
| 14 | **Launch** | Запустить выполнение сразу |
