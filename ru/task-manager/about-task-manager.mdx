## Обзор

Task manager — центральная панель для всех запланированных и выполняемых задач. Задачи создаются в [модуле переводов](/ru/transfers/about-transfers) и отслеживаются во вкладках **Scheduled**, **Processing** и **Archive**.

<Frame><img src="/images/atmos_ui/task_manager/atmos_task_manager_tasks_dashboard.png" alt="Task manager dashboard" /></Frame>

## Вкладки задач

### Scheduled

Задачи, которые ждут запуска в выбранные дату и время.

| Колонка | Описание |
|---|---|
| **Wallets** | Общее число кошельков в задаче |
| **Created** | Когда задача была создана |
| **Scheduled** | Дата и время запуска |
| **Cancel** | Отменить задачу и перенести её в archive |
| **Open** | Открыть и изменить задачу |

### Processing

Задачи, которые выполняются прямо сейчас.

| Колонка | Описание |
|---|---|
| **Wallets** | Общее число кошельков в задаче |
| **Created** | Когда задача была создана |
| **Running since** | Когда началось выполнение |
| **Stop** | Остановить выполнение и перенести задачу в archive |
| **Open** | Открыть прогресс в реальном времени и логи |

### Archive

Завершённые, отменённые или остановленные задачи.

| Колонка | Описание |
|---|---|
| **Wallets** | Общее число кошельков в задаче |
| **Created** | Когда задача была создана |
| **Status** | Cancelled / Partially completed / Completed |
| **Open** | Открыть итоговые логи |

<Warning>
  Запланированные задачи выполняются локально. В выбранное время устройство и Oxygen Atmos должны быть запущены.
</Warning>
