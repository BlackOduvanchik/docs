## Посмотреть прогресс

Во вкладке **Processing** или **Archive** нажмите **Open** на задаче, чтобы открыть детали выполнения.

## Логи задачи

Нажмите **Logs**, чтобы посмотреть подробные записи с временными метками по операциям каждого кошелька. В записи лога видно:

- статус транзакции: success, pending или error
- сообщения статуса, например `Transaction sent, waiting for confirmation` или `Successfully transferred X to address`
- раскрываемые детали по шагам

## Статусы задач

| Статус | Описание |
|---|---|
| **Scheduled** | Ожидает запланированного времени запуска |
| **Processing** | Выполняется сейчас |
| **Queued** | Кошелёк ждёт обработки |
| **Completed** | Все операции успешно завершены |
| **Partially completed** | Часть кошельков выполнена успешно, часть завершилась с ошибкой |
| **Failed Error** | Задача завершилась с ошибками |
| **Cancelled** | Задача отменена вручную |

## Восстановление после ошибок

### Restart unsuccessful

Если у задачи статус **Partially completed**, нажмите **Restart unsuccessful**, чтобы повторно запустить задачу только для кошельков со статусом **Queued** или **Error**.

### Скопировать кошельки для точечного исправления

Если часть кошельков завершилась с ошибкой, например из-за нехватки gas, можно создать отдельную top-up задачу:

<Steps>
  <Step title="Откройте меню копирования">
    В окне задачи нажмите **copy icon** в правом нижнем углу.
  </Step>
  <Step title="Выберите вариант">
    Выберите один из вариантов:

    | Вариант | Описание |
    |---|---|
    | **Use as template** | Скопировать все параметры задачи в новую задачу |
    | **Copy all wallets** | Скопировать все кошельки в новую задачу |
    | **Copy wallets with errors** | Скопировать только кошельки со статусом error |
  </Step>
  <Step title="Настройте и запустите">
    Задайте параметры новой задачи, например отправку native token на кошельки с ошибками, затем запустите или отложите её.
  </Step>
</Steps>
