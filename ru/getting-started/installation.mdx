## Доступность

Oxygen Atmos доступен для **Windows** и **macOS**.

## Системные требования

| Требование | Минимум | Рекомендуется |
|---|---|---|
| **OS** | Windows 10 или macOS | Windows 11 или актуальная версия macOS |
| **RAM** | 4 GB | 8 GB+ |
| **Диск** | 2 GB свободного места | SSD с 10 GB+ |
| **CPU** | Dual-core | Quad-core+ |

## Скачать

Основной источник загрузки — сайт Oxygen. Те же ссылки на установщики доступны в Telegram-боте.

<Steps>
  <Step title="Скачайте установщик">
    Откройте [страницу загрузки](https://wallet.oxygen.tools/en/download) и скачайте установщик для своей операционной системы.
  </Step>
  <Step title="Альтернатива: Telegram-бот">
    Также можно открыть [Telegram-бот](https://t.me/OduLandBot?start=r_oxygen_x), отправить `/start`, выбрать **💎 Oxygen.Atmos** и перейти по ссылкам **Windows | MacOS**.
  </Step>
  <Step title="Запустите установщик">
    Откройте скачанный установщик и следуйте инструкциям на экране.
  </Step>
  <Step title="Откройте приложение">
    Запустите Oxygen Atmos, чтобы пройти первый запуск.
  </Step>
</Steps>

## Доступ через Telegram

Доступ к Oxygen Atmos, статус подписки и API key управляются через [Telegram-бот](https://t.me/OduLandBot?start=r_oxygen_x).

<Steps>
  <Step title="Откройте бота">
    Откройте [Telegram-бот](https://t.me/OduLandBot?start=r_oxygen_x) и отправьте `/start`.
  </Step>
  <Step title="Откройте Oxygen Atmos">
    В главном меню выберите **💎 Oxygen.Atmos**.
  </Step>
  <Step title="Выберите доступ">
    Можно начать с бесплатного тарифа: он включает **10 браузерных профилей**. Платный тариф выбирайте в боте только если нужен больший лимит профилей.
  </Step>
  <Step title="Скопируйте API key">
    Скопируйте **Персональный API ключ** в разделе Oxygen.Atmos. Он понадобится при первом запуске приложения.
  </Step>
</Steps>

## Первый запуск

При первом запуске Oxygen Atmos нужно пройти два шага:

<Steps>
  <Step title="Введите API key">
    Вставьте API key из [Telegram-бота](https://t.me/OduLandBot?start=r_oxygen_x). Это активирует приложение.

    <Frame><img src="/images/atmos_ui/onboarding/atmos_first_time_setup_1.png" alt="First time setup — API key entry" /></Frame>

  </Step>
  <Step title="Задайте master password">
    Создайте master password, чтобы шифровать чувствительные данные, которые хранятся локально: приватные ключи, API keys и настройки. Можно выбрать **Continue without encryption**, но мы не рекомендуем работать без шифрования.
  </Step>
</Steps>

<Info>
  Данные хранятся локально. Oxygen Atmos не отправляет ваши ключи и учётные данные на внешние серверы.
</Info>

## Автообновления

Когда доступна новая версия, вы увидите уведомление в приложении. Чтобы обновиться, перезапустите Oxygen Atmos.

## Сброс данных при заблокированном хранилище

Oxygen Atmos не хранит и не восстанавливает master password. Если хранилище заблокировано и его не удаётся открыть с помощью master password или PIN-кода, нажмите **Forgot password?**, а затем выберите **reset the app**.

<Frame><img src="/images/atmos_ui/onboarding/atmos_login_reset_flow.png" alt="Заблокированное хранилище и переход к сбросу приложения" /></Frame>

<Warning>Сброс удаляет все данные, добавленные в Oxygen Atmos на этом устройстве. Если вы не уверены, обратитесь в поддержку. После повторной настройки можно импортировать ранее экспортированную резервную копию.</Warning>
