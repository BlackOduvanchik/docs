## Обзор

Модуль переводов включает два инструмента:

- **CEX withdrawal** — вывод токенов с подключённых биржевых аккаунтов на ваши кошельки
- **Wallet withdrawal** — отправка токенов с ваших кошельков на биржевые deposit addresses или другие адреса

Оба инструмента поддерживают шаблоны, предпросмотр перед запуском и планирование через [Task manager](/ru/task-manager/about-task-manager).

## Возможности

| Возможность | CEX withdrawal | Wallet withdrawal |
|---|---|---|
| Гибкая настройка суммы | Да | Да |
| Проверка баланса | Да | Да |
| Сравнение fee между биржами | Да | — |
| Вывод по проценту | — | Да |
| Отправка на связанные адреса | — | Да |
| Отправка на один адрес | — | Да |
| Шаблоны | Да | Да |
