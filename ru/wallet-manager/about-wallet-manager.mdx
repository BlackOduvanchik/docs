## Что такое менеджер кошельков

Менеджер кошельков — основной модуль Oxygen Atmos. Здесь начинаются ключевые сценарии: импорт кошельков, отслеживание балансов, организация через теги и подготовка кошельков для переводов или создания браузерных профилей.

<Frame><img src="/images/atmos_ui/wallets/atmos_wallets_5wallets.png" alt="Wallet manager with imported wallets" /></Frame>

## Основные возможности

| Возможность | Описание |
|---|---|
| **Отслеживание балансов** | Общий баланс портфеля по всем импортированным кошелькам и лимит кошельков, например `5 / 500` |
| **Массовое управление** | Импорт, редактирование и назначение тегов для сотен кошельков |
| **Гибкий импорт** | Добавление по одному, списком или из CSV/XLS/XLSX файлов |
| **Система тегов** | [Единые теги](/ru/additional-features/settings) для кошельков и браузерных профилей |
| **Фильтры и сортировка** | Быстрый поиск по тегам, alias, балансу или типу |

<Note>
  Кошельки можно импортировать через **private key** для полного доступа или через **public address** только для мониторинга баланса.
</Note>

## Как это работает

Импортированные кошельки хранят данные локально на вашем устройстве. Чувствительные данные, включая private keys, API keys и настройки, шифруются и не отправляются на внешние серверы.

Из менеджера кошельков можно:

- отслеживать балансы всех кошельков в одном списке
- создавать браузерные профили, связанные с конкретными кошельками
- организовывать кошельки через [теги](/ru/additional-features/settings) и массовые действия: выбор, копирование, удаление
