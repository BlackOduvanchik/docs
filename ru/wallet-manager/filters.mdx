## Быстрые фильтры

Панель над списком кошельков даёт быстрый доступ к фильтрам:

- **Tags** — нажмите **Tags**, чтобы отфильтровать список по одному или нескольким тегам. Нажмите **Reset**, чтобы сбросить фильтр.
- **Search** — введите alias или адрес кошелька, чтобы отфильтровать список в реальном времени.

## Фильтры баланса

Нажмите **filter icon**, чтобы открыть окно фильтров:

| Фильтр | Описание |
|---|---|
| **Don't show assets worth less than** | Скрыть токены ниже заданного долларового порога |
| **Show only verified assets** | Исключить непроверенные токены |
| **Show maximum number of chains** | Ограничить число сетей, отображаемых для одного кошелька |
| **Show maximum number of protocols** | Ограничить число протоколов для одного кошелька |
| **Show maximum number of assets** | Ограничить число отдельных активов для одного кошелька |

## Сортировка

Сортируйте список кошельков нажатием на заголовок колонки:

| Колонка | Сортировка |
|---|---|
| **Alias** | Отображаемое имя кошелька по алфавиту |
| **Balance** | Баланс токенов по возрастанию или убыванию |

Нажмите на заголовок один раз для сортировки по возрастанию, второй раз — по убыванию.
