## Overview

Secure notes are private notes attached to a browser profile. Use them for profile-specific information that should stay with the profile, such as workflow details, account reminders, or operational context.

Secure notes stay in Oxygen Atmos. They are not injected into websites and are not exposed to the launched browser.

## Storage

Secure notes are stored locally and encrypted.

## Edit notes

You can edit notes from:

- the profile creation or edit dialog
- the secure notes action in the profile table

## Use cases

| Use case | Example note |
|---|---|
| **Workflow context** | `Warmup completed — ready for marketplace flow` |
| **Campaign tracking** | `Lighter Regional Competition — started 2026-01-15` |
| **Status** | `Proxy changed on 2026-02-01` |
| **Instructions** | `Keep this profile on the current browser version` |
