## 概览

Secure notes 是附加到浏览器配置文件的私人备注。可用于保存需要跟随配置文件的专属信息，例如流程细节、账户提醒或操作上下文。

Secure notes 会保留在 Oxygen Atmos 中。它们不会注入网站，也不会暴露给启动后的浏览器。

## 存储

Secure notes 会在本地加密存储。

## 编辑备注

你可以在以下位置编辑备注：

- 配置文件创建或编辑窗口
- 配置文件表格中的 secure notes 操作

## 使用场景

| 使用场景 | 示例备注 |
|---|---|
| **流程上下文** | `Warmup completed — ready for marketplace flow` |
| **Campaign 跟踪** | `Lighter Regional Competition — started 2026-01-15` |
| **状态** | `Proxy changed on 2026-02-01` |
| **说明** | `Keep this profile on the current browser version` |
