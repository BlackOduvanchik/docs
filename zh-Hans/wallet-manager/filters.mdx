## 快速筛选

钱包列表上方的工具栏提供快速筛选：

- **Tags**：点击 **Tags**，按一个或多个标签筛选。点击 **Reset** 清除筛选。
- **Search**：输入钱包 alias 或地址，列表会实时过滤。

## 余额筛选

点击**筛选图标**打开筛选窗口，可使用以下选项：

| 筛选项 | 说明 |
|---|---|
| **Don't show assets worth less than** | 隐藏低于指定美元价值的 token |
| **Show only verified assets** | 排除未验证 token |
| **Show maximum number of chains** | 限制每个钱包显示的 chain 数量 |
| **Show maximum number of protocols** | 限制每个钱包显示的协议数量 |
| **Show maximum number of assets** | 限制每个钱包显示的单个资产数量 |

## 排序

点击任意列标题即可对钱包列表排序：

| 列 | 排序依据 |
|---|---|
| **Alias** | 钱包显示名称，按字母排序 |
| **Balance** | Token 余额，升序或降序 |

点击一次列标题为升序，再次点击为降序。
