## Main

打开 **Settings**。**Main** 包含 API Key、Master Password、PIN code、Language、Export files 和 Import files。

<Frame><img src="/images/atmos_ui/settings/atmos_settings_main_v040.png" alt="Settings Main" /></Frame>

你可以将 Wallets、Accounts 或 Software settings 导出为 ZIP。启用 **Set encryption password** 可使用密码保护存档。导入文件仅在本地处理，不会上传到服务器。

## Connection

<Frame><img src="/images/atmos_ui/settings/atmos_settings_connection.png" alt="Settings Connection" /></Frame>

选择 **System proxy** 或 **Custom proxy**。你可以分别为 Oxygen API、Wallet RPC、Portfolio data 和 CEX accounts 设置路由。钱包、关联配置文件或 CEX 账户自己的代理在已配置时具有优先权。

<Note>Browser profiles 始终使用配置文件中保存的代理。Connection 不会更改浏览器配置文件流量。</Note>
