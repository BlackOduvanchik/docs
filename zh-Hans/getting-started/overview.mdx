## 欢迎使用 Oxygen Atmos

Oxygen Atmos 是一款桌面应用，将基于 Chromium 的反检测浏览器和完整的 Web3 钱包管理整合在一起。每个浏览器配置文件都是独立环境，拥有自己的数字指纹；内置模块则用于批量管理钱包、交易所账户和加密货币转账。

## 开始使用

<Steps>
  <Step title="下载应用">
    在你的设备上[下载并安装](/zh-Hans/getting-started/installation) Oxygen Atmos。
  </Step>
  <Step title="在 Telegram 中获取访问权限">
    打开 [Telegram 机器人](https://t.me/OduLandBot?start=r_oxygen_x)，发送 `/start`，选择 **💎 Oxygen.Atmos**，然后复制你的 API key。
  </Step>
  <Step title="首次设置">
    输入 API key，并设置 [master password](/zh-Hans/getting-started/installation) 来加密本地数据。
  </Step>
  <Step title="创建配置文件">
    创建第一个带有独立指纹的[浏览器配置文件](/zh-Hans/browser-profiles/about-profiles)。
  </Step>
</Steps>

## 使用场景

| 使用场景 | 说明 |
|---|---|
| **Airdrop farming** | 使用隔离指纹、代理和会话持久化，在多个协议中运行 50 到 500+ 个钱包 |
| **DeFi 与交易** | 为 DEX、借贷、perps 和跨链桥创建隔离配置文件。每个配置文件都有自己的钱包、代理和会话，并可按配置文件访问有地区限制的前端 |
| **钱包管理** | 使用已绑定的浏览器配置文件、标签和活动备注跟踪钱包活动 |
| **团队操作** | 通过 PIN 保护的配置文件、标签和分组协调团队 farming 流程 |
