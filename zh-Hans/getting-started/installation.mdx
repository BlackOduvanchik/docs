## 可用平台

Oxygen Atmos 支持 **Windows** 和 **macOS**。

## 系统要求

| 要求 | 最低配置 | 推荐配置 |
|---|---|---|
| **OS** | Windows 10 或 macOS | Windows 11 或最新版 macOS |
| **RAM** | 4 GB | 8 GB+ |
| **Disk** | 2 GB 可用空间 | SSD，10 GB+ 可用空间 |
| **CPU** | 双核 | 四核或更高 |

## 下载

主要下载入口是 Oxygen 网站。同样的安装程序链接也可以在 Telegram 机器人中找到。

<Steps>
  <Step title="下载安装程序">
    打开[下载页面](https://wallet.oxygen.tools/en/download)，下载适合你操作系统的安装程序。
  </Step>
  <Step title="备选方式：Telegram 机器人">
    你也可以打开 [Telegram 机器人](https://t.me/OduLandBot?start=r_oxygen_x)，发送 `/start`，选择 **💎 Oxygen.Atmos**，并使用 **Windows | MacOS** 下载链接。
  </Step>
  <Step title="运行安装程序">
    打开下载好的安装程序，并按照屏幕提示完成安装。
  </Step>
  <Step title="启动应用">
    打开 Oxygen Atmos，开始首次设置。
  </Step>
</Steps>

## 通过 Telegram 获取访问权限

Oxygen Atmos 的访问权限、订阅状态和 API key 都通过 [Telegram 机器人](https://t.me/OduLandBot?start=r_oxygen_x) 管理。

<Note>
  Telegram 机器人目前只有俄语界面。下面的按钮名称会按机器人中的原文显示。
</Note>

<Steps>
  <Step title="打开机器人">
    打开 [Telegram 机器人](https://t.me/OduLandBot?start=r_oxygen_x) 并发送 `/start`。
  </Step>
  <Step title="打开 Oxygen Atmos">
    在主菜单中选择 **💎 Oxygen.Atmos**。
  </Step>
  <Step title="选择访问权限">
    你可以从免费方案开始。免费方案包含 **10 个浏览器配置文件**。只有需要更高配置文件上限时，才需要在机器人中选择付费方案。
  </Step>
  <Step title="复制 API key">
    复制 Oxygen.Atmos 区域中的 **Персональный API ключ**。首次启动应用时需要使用它。
  </Step>
</Steps>

## 首次设置

第一次启动 Oxygen Atmos 时，需要完成两个设置步骤：

<Steps>
  <Step title="输入 API key">
    粘贴你从 [Telegram 机器人](https://t.me/OduLandBot?start=r_oxygen_x) 获取的 API key。这会激活应用。

    <Frame><img src="/images/atmos_ui/onboarding/atmos_first_time_setup_1.png" alt="首次设置：输入 API key" /></Frame>

  </Step>
  <Step title="设置 master password">
    创建 master password，用于加密本机保存的所有敏感数据，包括私钥、API key 和设置。你也可以选择 **Continue without encryption**，但不推荐这样做。
  </Step>
</Steps>

<Info>
  所有数据都存储在本机。Oxygen Atmos 不会把你的密钥或凭据发送到外部服务器。
</Info>

## 自动更新

当有新版本可用时，应用内会显示通知。重启 Oxygen Atmos 即可更新。

## 保险库锁定时重置应用数据

Oxygen Atmos 不会保存或恢复你的 master password。如果保险库已锁定，并且无法使用 master password 或 PIN 解锁，请点击 **Forgot password?**，然后选择 **reset the app**。

<Frame><img src="/images/atmos_ui/onboarding/atmos_login_reset_flow.png" alt="已锁定的保险库和重置应用选项" /></Frame>

<Warning>重置会删除此设备上添加到 Oxygen Atmos 的全部数据。如果不确定，请先联系支持团队。重新设置应用后，可以导入之前导出的备份。</Warning>
