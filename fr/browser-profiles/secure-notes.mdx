## Vue d'ensemble

Secure notes sont des notes privées attachées à un profil navigateur. Utilisez-les pour les informations qui doivent rester avec le profil: détails de workflow, rappels de compte ou contexte opérationnel.

Secure notes restent dans Oxygen Atmos. Elles ne sont pas injectées dans les sites et ne sont pas exposées au navigateur lancé.

## Stockage

Secure notes sont stockées localement et chiffrées.

## Modifier les notes

Vous pouvez modifier les notes depuis:

- le dialogue de création ou d'édition du profil
- l'action secure notes dans le tableau des profils

## Exemples

| Cas | Exemple |
|---|---|
| **Contexte workflow** | `Warmup completed — ready for marketplace flow` |
| **Suivi campagne** | `Lighter Regional Competition — started 2026-01-15` |
| **Statut** | `Proxy changed on 2026-02-01` |
| **Instruction** | `Keep this profile on the current browser version` |
