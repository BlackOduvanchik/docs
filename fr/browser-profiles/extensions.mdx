---
title: "Extensions"
description: "Installer des extensions globalement ou selon les tags des profils"
---

Ouvrez **Browser → Extensions** pour gérer les extensions [Oxidium](/fr/browser-profiles/oxidium).

<Frame><img src="/images/atmos_ui/browser/atmos_browser_extensions.png" alt="Gestionnaire d'extensions" /></Frame>

Cliquez sur **Add**, puis choisissez **Upload file** ou **URL address** depuis le Chrome Web Store. Une extension peut être globale, chargée selon les tags ou désactivée. Utilisez **Search**, **Tags** et **Update extensions**. Relancez les profils après une modification.
