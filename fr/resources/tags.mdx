---
title: "Tags"
description: "Gérer les tags partagés entre wallets, profils, comptes CEX, extensions et favoris"
---

Ouvrez **Resources → Tags**. Les tags sont disponibles dans tous les modules Oxygen Atmos.

<Frame><img src="/images/atmos_ui/resources/atmos_resources_tags.png" alt="Tableau des tags" /></Frame>

Le tableau affiche **Name**, **Color**, l'utilisation dans Browsers, Wallets, Accounts, Extensions et Bookmarks, ainsi que les Actions. Filtrez avec **Search**, **Colors** et **Show only unused**. Cliquez sur **Add tag** pour créer un tag.

Dans [Bookmarks manager](/fr/browser-profiles/bookmarks-manager), les tags déterminent les groupes de profils auxquels un favori est ajouté.

<Warning>Supprimer un tag le retire de tous les éléments sans supprimer les éléments eux-mêmes.</Warning>
