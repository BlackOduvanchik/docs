---
title: "Tags"
description: "Gérer les tags partagés entre wallets, profils, comptes CEX et extensions"
---

Ouvrez **Resources → Tags**. Les tags sont disponibles dans tous les modules Oxygen Atmos.

<Frame><img src="/images/atmos_ui/resources/atmos_resources_tags.png" alt="Tableau des tags" /></Frame>

Le tableau affiche **Name**, **Color**, l'utilisation dans Browsers, Wallets, Accounts et Extensions, ainsi que les Actions. Filtrez avec **Search**, **Colors** et **Show only unused**. Cliquez sur **Add tag** pour créer un tag.

<Warning>Supprimer un tag le retire de tous les éléments sans supprimer les éléments eux-mêmes.</Warning>
