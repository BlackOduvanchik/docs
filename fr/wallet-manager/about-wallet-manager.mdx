## Vue d'ensemble

Le Wallet manager est l'espace central pour les wallets EVM dans Oxygen Atmos. Vous pouvez y importer des wallets, attribuer des tags, définir des withdrawal addresses, suivre les balances et relier des wallets à des profils navigateur.

<Frame><img src="/images/atmos_ui/wallets/atmos_wallets_manager_v040.png" alt="Gestionnaire de wallets" /></Frame>

## Tableau

| Colonne | Description |
|---|---|
| **Address** | Adresse EVM du wallet |
| **Alias** | Nom court pour la recherche |
| **Tags** | Groupes et labels du wallet |
| **Withdrawal address** | Adresse par défaut pour les transferts sortants |
| **Browser profile** | Profil navigateur lié, s'il existe |
| **Balances** | Tokens détectés et montants |

## Stockage local

Les wallets importés stockent leurs données localement sur votre machine. Les données sensibles — private keys, API keys et paramètres — sont chiffrées et ne sont pas envoyées à des serveurs externes.

## Actions principales

- importer un wallet, une liste ou un fichier
- modifier alias, tags ou withdrawal address
- vérifier les balances sur les networks pris en charge
- filtrer les wallets par tags, balances ou profils liés
- utiliser les wallets dans les [profils navigateur](/fr/browser-profiles/about-profiles)
- utiliser les wallets dans les [transferts](/fr/transfers/about-transfers)
