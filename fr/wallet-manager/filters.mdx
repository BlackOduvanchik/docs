## Vue d'ensemble

Les filtres aident à travailler avec de longues listes de wallets. Combinez recherche, tags, networks et options de balance pour afficher uniquement les entrées utiles.

## Filtres disponibles

| Filtre | Description |
|---|---|
| **Search** | Recherche par address ou alias |
| **Tags** | Afficher les wallets avec certains tags |
| **Networks** | Afficher les wallets actifs sur certains networks |
| **Tokens** | Filtrer par token balances |
| **Browser profile** | Afficher les wallets avec ou sans profil lié |
| **Show maximum number of protocols** | Limiter le nombre de protocoles par wallet |

## Filtrer par tags

<Steps>
  <Step title="Ouvrir Tags">
    Cliquez sur **Tags** au-dessus du tableau.
  </Step>
  <Step title="Choisir les tags">
    Sélectionnez un ou plusieurs tags. Le tableau affiche uniquement les wallets correspondants.
  </Step>
  <Step title="Réinitialiser">
    Cliquez sur **Reset** pour revenir à la liste complète.
  </Step>
</Steps>

## Conseils

- Utilisez les tags pour les campaigns, networks ou types d'activité
- Combinez Search et Tags pour trouver vite un wallet précis
- Vérifiez le linked browser profile avant de supprimer un wallet
