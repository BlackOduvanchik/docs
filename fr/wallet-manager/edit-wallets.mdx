## Modifier un wallet

<Steps>
  <Step title="Ouvrir Wallet manager">
    Ouvrez **Wallet manager**.
  </Step>
  <Step title="Choisir un wallet">
    Recherchez l'address ou l'alias dans le tableau.
  </Step>
  <Step title="Ouvrir l'édition">
    Cliquez sur l'action d'édition dans la ligne du wallet.
  </Step>
  <Step title="Mettre à jour les champs">
    Modifiez alias, tags ou withdrawal address.
  </Step>
  <Step title="Enregistrer">
    Confirmez les changements.
  </Step>
</Steps>

## Modifier plusieurs wallets

Pour mettre à jour withdrawal address ou alias pour plusieurs wallets, réimportez-les avec les données mises à jour via une des [méthodes d'import](/fr/wallet-manager/import-wallets).

Si l'address existe déjà, Oxygen Atmos met à jour les champs sans créer de doublon.

## Profils liés

Si un wallet est utilisé dans un profil navigateur, modifier alias ou tags ne rompt pas le lien. Supprimer un wallet peut affecter les profils où il est utilisé comme main wallet ou additional wallet.
