## Disponibilité

Oxygen Atmos est disponible pour **Windows** et **macOS**.

## Prérequis système

| Prérequis | Minimum | Recommandé |
|---|---|---|
| **OS** | Windows 10 ou macOS | Windows 11 ou version macOS récente |
| **RAM** | 4 GB | 8 GB+ |
| **Disque** | 2 GB libres | SSD avec 10 GB+ |
| **CPU** | Dual-core | Quad-core+ |

## Téléchargement

<Steps>
  <Step title="Télécharger l'installateur">
    Allez sur [wallet.oxygen.tools/en/download](https://wallet.oxygen.tools/en/download) et téléchargez l'installateur pour votre système.
  </Step>
  <Step title="Lancer l'installateur">
    Ouvrez le fichier téléchargé et suivez les instructions à l'écran.
  </Step>
  <Step title="Ouvrir l'application">
    Lancez Oxygen Atmos pour commencer la première configuration.
  </Step>
</Steps>

## Première configuration

Au premier lancement, Oxygen Atmos demande deux étapes:

<Steps>
  <Step title="Entrer l'API key">
    Collez l'API key de votre compte [wallet.oxygen.tools](https://wallet.oxygen.tools). Elle active l'application.

    <Frame><img src="/images/atmos_ui/onboarding/atmos_first_time_setup_1.png" alt="First time setup — API key entry" /></Frame>
  </Step>
  <Step title="Définir un master password">
    Créez un master password pour chiffrer les données sensibles stockées localement: private keys, API keys et paramètres. **Continue without encryption** est possible, mais déconseillé.
  </Step>
</Steps>

<Info>
  Les données restent locales. Oxygen Atmos n'envoie pas vos keys ni vos identifiants à des serveurs externes.
</Info>

## Auto-updates

Quand une nouvelle version est disponible, une notification apparaît dans l'application. Redémarrez Oxygen Atmos pour mettre à jour.
