## Créer un compte

<Steps>
  <Step title="Ouvrir la page d'inscription">
    Allez sur [wallet.oxygen.tools/en](https://wallet.oxygen.tools/en) et cliquez sur **Sign Up**.
  </Step>
  <Step title="Entrer vos informations">
    Indiquez votre email et créez un mot de passe. Si l'option existe, vous pouvez aussi utiliser un fournisseur tiers.
  </Step>
  <Step title="Confirmer l'email">
    Ouvrez l'email de vérification et cliquez sur le lien de confirmation.
  </Step>
  <Step title="Se connecter">
    Revenez à la page de connexion et connectez-vous. Le dashboard principal s'ouvrira ensuite.
  </Step>
</Steps>

## Obtenir votre API key

Après l'inscription, ouvrez les paramètres de votre compte sur [wallet.oxygen.tools](https://wallet.oxygen.tools) pour trouver votre API key. Elle est nécessaire pour activer l'application desktop lors de la première configuration.

<Info>
  L'API key est saisie une seule fois au premier lancement d'Oxygen Atmos. Elle relie l'application desktop à votre compte.
</Info>
