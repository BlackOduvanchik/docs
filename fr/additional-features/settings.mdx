## Main

Ouvrez **Settings**. L'onglet **Main** contient API Key, Master Password, PIN code, Language, Export files et Import files.

<Frame><img src="/images/atmos_ui/settings/atmos_settings_main_v040.png" alt="Settings Main" /></Frame>

Exportez Wallets, Accounts ou Software settings dans un ZIP. Activez **Set encryption password** pour protéger l'archive. Les imports sont traités localement et ne sont pas envoyés sur un serveur.

## Connection

<Frame><img src="/images/atmos_ui/settings/atmos_settings_connection.png" alt="Settings Connection" /></Frame>

Choisissez **System proxy** ou **Custom proxy**. Le routage se configure séparément pour Oxygen API, Wallet RPC, Portfolio data et CEX accounts. Le proxy d'un wallet, d'un profil lié ou d'un compte CEX est prioritaire lorsqu'il existe.

<Note>Browser profiles utilisent toujours le proxy enregistré dans le profil. Connection ne modifie pas ce trafic.</Note>
