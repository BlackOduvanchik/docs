## Подивитися прогрес

У вкладці **Processing** або **Archive** натисніть **Open** на задачі, щоб відкрити деталі виконання.

## Логи задачі

Натисніть **Logs**, щоб подивитися докладні записи з часовими мітками по операціях кожного гаманця. У записі лога видно:

- статус транзакції: success, pending або error
- повідомлення статусу, наприклад `Transaction sent, waiting for confirmation` або `Successfully transferred X to address`
- розкривні деталі по кроках

## Статуси задач

| Статус | Опис |
|---|---|
| **Scheduled** | Очікує запланованого часу запуску |
| **Processing** | Виконується зараз |
| **Queued** | Гаманець чекає обробки |
| **Completed** | Усі операції успішно завершені |
| **Partially completed** | Частина гаманців виконана успішно, частина завершилася з помилкою |
| **Failed Error** | Задача завершилася з помилками |
| **Cancelled** | Задача скасована вручну |

## Відновлення після помилок

### Restart unsuccessful

Якщо задача має статус **Partially completed**, натисніть **Restart unsuccessful**, щоб повторно запустити задачу тільки для гаманців зі статусом **Queued** або **Error**.

### Скопіювати гаманці для точкового виправлення

Якщо частина гаманців завершилася з помилкою, наприклад через нестачу gas, можна створити окрему top-up задачу:

<Steps>
  <Step title="Відкрийте меню копіювання">
    У вікні задачі натисніть **copy icon** у правому нижньому куті.
  </Step>
  <Step title="Виберіть варіант">
    Виберіть один із варіантів:

    | Варіант | Опис |
    |---|---|
    | **Use as template** | Скопіювати всі параметри задачі в нову задачу |
    | **Copy all wallets** | Скопіювати всі гаманці в нову задачу |
    | **Copy wallets with errors** | Скопіювати тільки гаманці зі статусом error |
  </Step>
  <Step title="Налаштуйте й запустіть">
    Задайте параметри нової задачі, наприклад відправлення native token на гаманці з помилками, потім запустіть або відкладіть її.
  </Step>
</Steps>
