## Створити заплановану задачу

Задачі створюються з [модуля переказів](/uk/transfers/about-transfers): CEX withdrawal або wallet withdrawal.

<Steps>
  <Step title="Налаштуйте переказ">
    Перейдіть у **Transfers** у лівому сайдбарі та задайте параметри виведення.
  </Step>
  <Step title="Перевірте Preview">
    Натисніть **Preview**, щоб перевірити операцію.
  </Step>
  <Step title="Відкладіть запуск">
    Натисніть **Postpone** замість **Launch**.
  </Step>
  <Step title="Задайте розклад">
    Виберіть **date and time** для виконання.

    <Warning>
      Пристрій і Oxygen Atmos мають залишатися запущеними, щоб задача виконалася у вибраний час.
    </Warning>
  </Step>
  <Step title="Підтвердьте">
    Задача з'явиться у вкладці **Scheduled** в Task manager.
  </Step>
</Steps>

## Редагувати заплановану задачу

У вкладці **Scheduled** натисніть **Open** на потрібній задачі, щоб подивитися та змінити її. Зміни зберігаються автоматично, коли ви закриваєте вікно редагування.

<Frame><img src="/images/atmos_ui/task_manager/atmos_task_manager_tasks_edit_menu.png" alt="Task editing menu with numbered elements" /></Frame>

## Елементи меню редагування

| # | Елемент | Опис |
|---|---|---|
| 1 | **Scheduled** | Дата й час запуску задачі |
| 2 | **Logs** | Загальний лог задачі |
| 3 | **Config** | Workers, delays, retries; недоступно для редагування під час виконання задачі |
| 4 | **Action row** | Інформація про дію для конкретного гаманця |
| 5 | **Token withdrawal amount** | Сума виведення на гаманець; недоступно для редагування під час виконання задачі |
| 6 | **Status** | Поточний статус дії |
| 7 | **Wallets** | Прогрес за завершеними гаманцями |
| 8 | **Withdrawal amount** | Загальна сума виведення по всіх гаманцях |
| 9 | **Fee** | Загальна комісія по всіх гаманцях |
| 10 | **Processing time** | Загальний час виконання |
| 11 | **Use as template** | Меню копіювання: use as template, copy all wallets або copy wallets with errors |
| 12 | **Postpone** | Змінити дату й час запуску |
| 13 | **Cancel** | Скасувати задачу |
| 14 | **Launch** | Запустити виконання одразу |
