## Огляд

Secure notes — приватні нотатки, прикріплені до браузерного профілю. Використовуйте їх для інформації, яка має залишатися поруч із профілем: деталі процесу, нагадування по акаунту або робочий контекст.

Secure notes залишаються в Oxygen Atmos. Вони не інжектяться в сайти й не передаються в запущений браузер.

## Зберігання

Secure notes зберігаються локально та шифруються.

## Редагування нотаток

Нотатки можна редагувати з:

- вікна створення або редагування профілю
- дії secure notes у таблиці профілів

## Приклади використання

| Сценарій | Приклад нотатки |
|---|---|
| **Робочий контекст** | `Warmup completed — ready for marketplace flow` |
| **Трекінг кампанії** | `Lighter Regional Competition — started 2026-01-15` |
| **Статус** | `Proxy changed on 2026-02-01` |
| **Інструкція** | `Keep this profile on the current browser version` |
