## Що таке браузерний профіль

Браузерний профіль — це збережена браузерна ідентичність в Oxygen Atmos. Профілі розділяють акаунти, сесії, proxy, гаманці, цифрові відбитки, cookies, local storage, розширення та налаштування браузера.

Oxygen Atmos зберігає та застосовує конфігурацію профілю. [Oxidium](/uk/browser-profiles/oxidium) — ядро, сумісне з Chromium, яке відкривається під час запуску профілю.

## Таблиця профілів

На сторінці Browser відображається інформація для щоденної роботи:

| Колонка | Опис |
|---|---|
| **Alias** | Назва профілю в таблиці та в браузерному вікні |
| **Fingerprint** | Версія браузера та label відбитка |
| **Tags** | Теги для фільтрації та завантаження розширень |
| **Proxy** | Призначений proxy IP або статус відсутнього proxy |
| **Last launch** | Останній запуск профілю |
| **Actions** | Запуск, фокус, редагування та інші дії |

Пошук працює за alias, адресою пов'язаного гаманця, версією браузера, fingerprint label, proxy URL або proxy IP. Щоб показати групу профілів, натисніть на тег або використайте фільтр **Tags**.

## Дії з профілем

Основні дії:

- запустити закритий профіль
- сфокусувати вже запущений профіль
- закрити запущений профіль
- змінити налаштування профілю
- змінити пов'язані гаманці
- змінити теги
- змінити proxy
- відкрити secure notes
- видалити профіль

Вибрані профілі також можна обробляти масово: запускати, закривати, змінювати теги, перейменовувати або видаляти.

## Компоненти відбитка

Кожен профіль використовує узгоджений набір браузерних параметрів:

| Параметр | Опис |
|---|---|
| **Версія браузера** | Версія [Oxidium](/uk/browser-profiles/oxidium), яка в інтерфейсі показується як Chrome major version |
| **User-Agent** | Рядок ідентифікації браузера та OS |
| **Client Hints** | Chromium Client Hints у headers і JavaScript |
| **Screen resolution** | Розміри екрана |
| **Platform** | Ідентифікатор OS, наприклад Windows 10.0 |
| **Language** | Мова та locale браузера |
| **Timezone** | Часовий пояс |
| **Geolocation** | Режим доступу та джерело геолокації |
| **WebRTC** | Політика мережевого розкриття |
| **Canvas** | Noise для Canvas |
| **Audio** | Noise для AudioContext |
| **Rectangles** | Noise для DOM Rectangles |
| **WebGL** | GPU metadata і поведінка рендеру |

<Info>
  Fingerprint генерується до збереження профілю. Попередній перегляд відображає вибрану версію браузера та налаштування браузера.
</Info>

## Статуси профілю

| Статус | Опис |
|---|---|
| **Running** | Браузерне вікно зараз відкрите |
| **Not used** | Браузер закритий, дані збережені |

## Створення профілю

<Steps>
  <Step title="Натисніть New Profile">
    Натисніть **New Profile** у правому верхньому куті.
  </Step>
  <Step title="Задайте ідентичність профілю">
    Введіть alias і виберіть або створіть теги. Теги допомагають фільтрувати профілі та керувати тим, які розширення будуть завантажуватися.
  </Step>
  <Step title="Прив'яжіть гаманці">
    Виберіть гаманці, якщо профілю потрібна wallet integration. Вбудоване розширення Rabby дає браузерний інтерфейс для роботи з гаманцем.
  </Step>
  <Step title="Виберіть версію браузера">
    Виберіть версію браузера. Увімкніть **Keep up to date**, якщо хочете, щоб Oxygen Atmos міг переносити профіль на одну з останніх підтримуваних версій.
  </Step>
  <Step title="Перевірте fingerprint">
    Перевірте попередній перегляд відбитка. Він включає user agent, platform, language, app language, timezone, geolocation, WebRTC, WebGL і noise settings.

    <Frame><img src="/images/atmos_ui/browser/atmos_browser_new_profile.png" alt="Create new profile with fingerprint preview" /></Frame>
  </Step>
  <Step title="Додайте proxy">
    Якщо профілю потрібна окрема мережева локація, додайте proxy. Підтримуються **HTTP** і **SOCKS5**.

    Формати proxy:

    ```text
    protocol://host:port:user:pass
    protocol://user:pass@host:port
    ```
  </Step>
  <Step title="Додайте cookies або social tokens">
    Додайте cookies, X.com tokens або Discord tokens, якщо їх потрібно застосувати під час наступного запуску браузера.
  </Step>
  <Step title="Перевірте налаштування браузера">
    Використайте глобальні налаштування браузера або задайте перевизначення для конкретного профілю: search engine, language, timezone, geolocation, WebRTC policy, GPU spoofing mode або noise settings.
  </Step>
  <Step title="Збережіть профіль">
    Натисніть **Save profile**. Щоб запустити браузер, натисніть на рядок профілю.
  </Step>
</Steps>

## Редагування профілю

Після створення можна змінювати налаштування профілю. Деякі зміни застосовуються до збережених даних одразу, а параметри, пов'язані із запуском браузера, зазвичай потребують закрити та заново запустити профіль.

У режимі редагування не можна знизити версію браузера: можна залишити поточну або вибрати новішу.

## Гаманці в профілях

У кожного профілю може бути один main wallet на кожен тип гаманця. Main wallet має існувати в Oxygen Atmos, мати private key і не бути main wallet в іншому профілі.

Також можна додати additional wallets. Для additional wallet потрібен main wallet того самого типу. Якщо main wallet видалити, secondary wallets цього типу теж будуть видалені з профілю.

Під час запуску профілю пов'язані гаманці стають доступними для роботи з гаманцями в браузері. Private keys залишаються всередині Oxygen Atmos і не передаються в браузерне середовище.

## Proxy settings

У кожного профілю свій proxy. Підтримуються **HTTP** і **SOCKS5**.

Щоб змінити proxy, відкрийте редактор профілю та оновіть proxy fields.

Якщо proxy налаштований, Oxygen Atmos перевіряє його працездатність і зберігає доступні дані про локацію, наприклад країну та IP.

HTTP- і SOCKS5-проксі можна використовувати незалежно від підтримки UDP. Якщо проксі підтримує UDP, Atmos надсилає через нього WebRTC, QUIC і HTTP/3. Якщо UDP неможливо проксіювати, **Block unproxied UDP** блокує цей трафік і не допускає прямого з'єднання з розкриттям реальної IP-адреси. TCP-трафік продовжує працювати через налаштований проксі.

Видалення профілю переміщує його до кошика. У **Browser > Trash** профіль можна відновити або видалити назавжди.

## Ліміт профілів

Кількість доступних профілів залежить від поточного membership. Профілі понад ліміт позначаються як excessive і не можуть нормально використовуватися, доки ліміт не буде відновлено.
