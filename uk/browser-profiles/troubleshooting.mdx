Використовуйте цю сторінку, коли браузерний профіль не створюється, не запускається, не імпортується або працює не так, як очікується.

## Немає доступного fingerprint

Генерація fingerprint може не пройти, якщо немає відповідного відбитка для вибраної версії браузера, platform, architecture і GPU renderer.

Якщо інтерфейс пропонує повторну генерацію без GPU renderer matching, спробуйте цей варіант.

## Proxy check не проходить

Перевірте:

- host і port вказані правильно
- username і password вказані правильно
- proxy-сервер доступний
- поточна мережа може підключитися до proxy
- proxy підтримує HTTP або SOCKS5

Якщо в proxy не вказаний протокол, Oxygen Atmos під час імпорту спробує визначити, працює він як HTTP чи SOCKS5.

## Гаманець не прив'язується

Main wallet має:

- існувати в Oxygen Atmos
- мати private key
- не використовуватися як main wallet в іншому профілі

Read-only wallets не можна використовувати як основні браузерні гаманці.

## Cookies не з'являються

Імпортовані cookies застосовуються під час наступного запуску профілю. Якщо профіль уже був запущений, закрийте й відкрийте його знову.

Також перевірте domain, path, expiry і secure attributes у cookie.

## X.com або Discord token не застосовується

X.com token імпортується як cookie `auth_token` для `.x.com`.

Discord token імпортується в local storage для:

```text
https://discord.com/
```

Якщо token був доданий, коли профіль уже працював, закрийте й запустіть профіль заново.

## Розширення не завантажується

Перевірте:

- розширення увімкнене
- воно global або має спільний тег із профілем
- профіль був перезапущений після зміни розширень
- package розширення валідний

Набір розширень розраховується під час запуску профілю на [Oxidium](/uk/browser-profiles/oxidium).
