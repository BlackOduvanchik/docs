## Доступність

Oxygen Atmos доступний для **Windows** і **macOS**.

## Системні вимоги

| Вимога | Мінімум | Рекомендовано |
|---|---|---|
| **OS** | Windows 10 або macOS | Windows 11 або актуальна версія macOS |
| **RAM** | 4 GB | 8 GB+ |
| **Диск** | 2 GB вільного місця | SSD з 10 GB+ |
| **CPU** | Dual-core | Quad-core+ |

## Завантаження

Основне джерело завантаження — сайт Oxygen. Ті самі посилання на інсталятори доступні в Telegram-боті.

<Steps>
  <Step title="Завантажте інсталятор">
    Відкрийте [сторінку завантаження](https://wallet.oxygen.tools/en/download) і завантажте інсталятор для своєї операційної системи.
  </Step>
  <Step title="Альтернатива: Telegram-бот">
    Також можна відкрити [Telegram-бот](https://t.me/OduLandBot?start=r_oxygen_x), надіслати `/start`, вибрати **💎 Oxygen.Atmos** і скористатися посиланнями **Windows | MacOS**.
  </Step>
  <Step title="Запустіть інсталятор">
    Відкрийте завантажений інсталятор і дотримуйтеся інструкцій на екрані.
  </Step>
  <Step title="Відкрийте застосунок">
    Запустіть Oxygen Atmos, щоб пройти перше налаштування.
  </Step>
</Steps>

## Доступ через Telegram

Доступ до Oxygen Atmos, статус підписки та API key керуються через [Telegram-бот](https://t.me/OduLandBot?start=r_oxygen_x).

<Note>
  Інтерфейс Telegram-бота зараз доступний російською мовою. Назви кнопок нижче показані саме так, як вони виглядають у боті.
</Note>

<Steps>
  <Step title="Відкрийте бота">
    Відкрийте [Telegram-бот](https://t.me/OduLandBot?start=r_oxygen_x) і надішліть `/start`.
  </Step>
  <Step title="Відкрийте Oxygen Atmos">
    У головному меню виберіть **💎 Oxygen.Atmos**.
  </Step>
  <Step title="Виберіть доступ">
    Можна почати з безплатного тарифу: він включає **10 браузерних профілів**. Платний тариф у боті потрібен лише тоді, коли вам потрібен більший ліміт профілів.
  </Step>
  <Step title="Скопіюйте API key">
    Скопіюйте **Персональный API ключ** у розділі Oxygen.Atmos. Він знадобиться під час першого запуску застосунку.
  </Step>
</Steps>

## Перший запуск

Під час першого запуску Oxygen Atmos потрібно пройти два кроки:

<Steps>
  <Step title="Введіть API key">
    Вставте API key із [Telegram-бота](https://t.me/OduLandBot?start=r_oxygen_x). Це активує застосунок.

    <Frame><img src="/images/atmos_ui/onboarding/atmos_first_time_setup_1.png" alt="First time setup — API key entry" /></Frame>

  </Step>
  <Step title="Задайте master password">
    Створіть master password, щоб шифрувати чутливі дані, які зберігаються локально: private keys, API keys і налаштування. Можна вибрати **Continue without encryption**, але ми не рекомендуємо працювати без шифрування.
  </Step>
</Steps>

<Info>
  Дані зберігаються локально. Oxygen Atmos не надсилає ваші ключі та облікові дані на зовнішні сервери.
</Info>

## Автооновлення

Коли доступна нова версія, ви побачите сповіщення в застосунку. Щоб оновитися, перезапустіть Oxygen Atmos.

## Скидання даних, коли сховище заблоковано

Oxygen Atmos не зберігає та не відновлює master password. Якщо сховище заблоковано й ви не можете відкрити його за допомогою master password або PIN-коду, натисніть **Forgot password?**, а потім виберіть **reset the app**.

<Frame><img src="/images/atmos_ui/onboarding/atmos_login_reset_flow.png" alt="Заблоковане сховище та перехід до скидання застосунку" /></Frame>

<Warning>Скидання видаляє всі дані, додані до Oxygen Atmos на цьому пристрої. Якщо ви не впевнені, зверніться до підтримки. Після повторного налаштування можна імпортувати раніше експортовану резервну копію.</Warning>
