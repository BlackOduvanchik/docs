## Огляд

Фільтри допомагають працювати з великими списками гаманців. Можна комбінувати пошук, tags, networks і параметри балансів, щоб залишити тільки потрібні записи.

## Доступні фільтри

| Фільтр | Опис |
|---|---|
| **Search** | Пошук за address або alias |
| **Tags** | Показати гаманці з вибраними тегами |
| **Networks** | Показати гаманці з активністю в конкретних networks |
| **Tokens** | Фільтр за token balances |
| **Browser profile** | Показати гаманці, пов'язані або не пов'язані з профілями |
| **Show maximum number of protocols** | Обмежити число протоколів для одного гаманця |

## Фільтр за тегами

<Steps>
  <Step title="Відкрийте Tags">
    Натисніть **Tags** над таблицею гаманців.
  </Step>
  <Step title="Виберіть теги">
    Виберіть один або кілька тегів. Таблиця покаже тільки гаманці, які відповідають фільтру.
  </Step>
  <Step title="Скиньте фільтр">
    Натисніть **Reset**, щоб повернути повний список.
  </Step>
</Steps>

## Поради

- Використовуйте tags для campaigns, networks або типів активності
- Поєднуйте search і tags, щоб швидко знайти конкретний гаманець у великому списку
- Перевіряйте linked browser profile перед видаленням гаманця
