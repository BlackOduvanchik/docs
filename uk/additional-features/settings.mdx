## Огляд

Відкрийте **Settings** у лівому сайдбарі. Налаштування розділені на чотири вкладки: **Main**, **Tags**, **RPC** і **Browser**.

## Main

<Frame><img src="/images/atmos_ui/settings/atmos_settings_main.png" alt="Settings — Main tab" /></Frame>

| Налаштування | Опис |
|---|---|
| **API key** | Змінити API key, пов'язаний з акаунтом |
| **Master password** | Змінити master password для шифрування даних застосунку |
| **PIN code** | Задати або змінити PIN для підтвердження чутливих дій: переказів і видалення |
| **Language** | Мова інтерфейсу |

### Export

Дані можна експортувати як зашифровані ZIP-архіви. Доступні три категорії:

| Категорія | Вміст |
|---|---|
| **Wallets** | Дані гаманців, включно з тегами та персоналізацією |
| **Accounts** | Дані CEX accounts, включно з тегами та персоналізацією |
| **Software settings** | Налаштування RPC, розширення та інші налаштування застосунку |

### Import

Перетягніть раніше експортований зашифрований ZIP-архів або натисніть **Select**.

## Tags

Теги в Oxygen Atmos спільні для гаманців, браузерних профілів і exchange accounts. Тег, створений в одному місці, доступний всюди.

<Frame><img src="/images/atmos_ui/settings/atmos_settings_tags.png" alt="Tags management table" /></Frame>

### Таблиця тегів

| Колонка | Опис |
|---|---|
| **Name** | Назва тега з кольоровим індикатором |
| **Count** | Загальна кількість об'єктів із цим тегом |
| **Browsers** | Чекбокс: тег використовується в браузерних профілях |
| **Wallets** | Чекбокс: тег використовується в гаманцях |
| **Accounts** | Чекбокс: тег використовується в exchange accounts |
| **Extensions** | Кількість профілів із розширеннями, призначеними на цей тег |

Таблицю можна фільтрувати через **Colors**, **Search** і **Show only unused**.

### Створити тег

Натисніть **Add tag**, введіть **name** і виберіть **color**.

### Призначити теги

Теги можна призначати в кількох місцях:

- **Wallet manager** — під час імпорту або редагування гаманця
- **Browser profiles** — під час створення, масового створення або редагування профілю
- **Exchange accounts** — під час додавання або редагування акаунта

На один об'єкт можна призначити кілька тегів.

### Редагувати й видалити теги

- Натисніть іконку редагування, щоб змінити name або color тега. Зміни застосуються всюди, де використовується тег.
- Виберіть один або кілька тегів і натисніть **Delete**.

<Warning>
  Видалені теги автоматично видаляються з усіх гаманців, профілів і accounts, де вони були призначені.
</Warning>

### Фільтр за тегами

Список гаманців і список профілів підтримують фільтрацію за тегами:

1. Натисніть **Tags** над списком
2. Виберіть один або кілька тегів — залишаться тільки об'єкти з цими тегами
3. Натисніть **Reset**, щоб скинути фільтр

## RPC

Тут налаштовуються RPC endpoints для EVM chains.

| Налаштування | Опис |
|---|---|
| **Use global proxy for all RPCs** | Пропускати всі RPC requests через один proxy |
| **Use proxy from wallet browser profile** | Використовувати proxy браузерного профілю для RPC requests його гаманця |
| **Chain list** | Вмикати й вимикати chains, дивитися статус RPC |

У кожної chain є health indicator, наприклад **3/3** означає 3 здорові RPC з 3. Для кожної chain можна додати до **5 custom RPC endpoints**. Попередження `Low active RPCs` з'являється, коли частина endpoints не відповідає.

## Browser

Тут налаштовуються браузерні параметри за замовчуванням і керування розширеннями.

<Frame><img src="/images/atmos_ui/settings/atmos_settings_browser.png" alt="Settings — Browser tab" /></Frame>

### Browser preferences

Профілі можуть успадковувати глобальні налаштування браузера або перевизначати їх у редакторі профілю.

| Налаштування | Опис |
|---|---|
| **Search engine** | Search engine за замовчуванням для браузерних профілів |
| **Language** | За proxy IP address або вручну, наприклад English United States |
| **App language** | На основі **Language** або окремо |
| **Timezone** | За proxy IP address |
| **Geolocation** | Ask, Allow або Block, з опційним proxy IP source |
| **WebRTC** | Disable non-proxied UDP або public interface |
| **GPU spoofing** | Керування GPU metadata і spoofing mode |
| **Noise** | Перемикачі Canvas, Audio, Rectangles, WebGL |

Значення за замовчуванням:

| Налаштування | Значення за замовчуванням |
|---|---|
| **Search engine** | DuckDuckGo |
| **Language** | English (United States) |
| **App language** | Based on selected language |
| **Timezone** | Based on proxy IP address |
| **Geolocation** | Ask, based on proxy IP address |
| **WebRTC** | Disable non-proxied UDP |
| **GPU spoofing** | Strict |
| **Noise** | Canvas, Audio і DOM Rectangles увімкнені |

Перевизначення профілю використовуються під час генерації fingerprint і запуску браузера.

### Extensions

Oxygen Atmos керує розширеннями для профілів на [Oxidium](/uk/browser-profiles/oxidium). Розширення можна встановити глобально, призначити на теги профілів або вимкнути.

| Дія | Опис |
|---|---|
| **Add** | Встановити з Chrome Web Store URL або завантажити CRX/ZIP файл |
| **Update extensions** | Оновити всі встановлені розширення |
| **Delete** | Видалити розширення |

| Режим завантаження | Опис |
|---|---|
| **Global** | Завантажується в усі браузерні профілі |
| **Tag-based** | Завантажується тільки в профілі з хоча б одним спільним тегом із розширенням |
| **Disabled** | Не завантажується в жоден профіль |

Набір розширень розраховується під час запуску профілю. Після зміни призначення розширень, тегів або файлів розширення перезапустіть активний профіль.

<Info>
  **Rabby Wallet** — вбудоване розширення для роботи з гаманцями. Private keys залишаються всередині Oxygen Atmos і не передаються в браузерне середовище.
</Info>
