## Main

Відкрийте **Settings**. Вкладка **Main** містить API Key, Master Password, PIN code, Language, Export files та Import files.

<Frame><img src="/images/atmos_ui/settings/atmos_settings_main_v040.png" alt="Settings Main" /></Frame>

Експортуйте Wallets, Accounts або Software settings у ZIP. Увімкніть **Set encryption password**, щоб захистити архів. Імпорт обробляється локально й не завантажується на сервер.

## Connection

<Frame><img src="/images/atmos_ui/settings/atmos_settings_connection.png" alt="Settings Connection" /></Frame>

Виберіть **System proxy** або **Custom proxy**. Маршрут можна задати окремо для Oxygen API, Wallet RPC, Portfolio data та CEX accounts. Проксі гаманця, пов'язаного профілю або CEX-акаунта має пріоритет, коли він налаштований.

<Note>Browser profiles завжди використовують проксі, збережений у профілі. Connection не змінює їхній трафік.</Note>
