## Overview

Open **Resources → Tags** to manage tags shared across Oxygen Atmos.

<Frame><img src="/images/atmos_ui/resources/atmos_resources_tags.png" alt="Tags resource table" /></Frame>

A tag created in one module is available to wallets, browser profiles, exchange accounts, and extensions.

## Tag table

| Column | Description |
|---|---|
| **Name** | Tag name |
| **Color** | Visual color assigned to the tag |
| **Usage** | Number of browsers, wallets, accounts, and extensions using the tag |
| **Actions** | Edit or delete the tag |

Use **Search**, **Colors**, and **Show only unused** to filter the table.

## Create a tag

Click **Add tag**, enter a name, choose a color, and save it. You can then assign the tag while importing wallets, creating profiles, adding exchange accounts, or configuring extensions.

## Edit or delete tags

- Edit a tag to update its name or color everywhere it is used.
- Select one or more tags to delete them.

<Warning>
  Deleting a tag removes it from every wallet, profile, account, and extension where it is assigned. It does not delete those items.
</Warning>
