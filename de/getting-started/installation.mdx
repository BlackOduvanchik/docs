## Verfügbarkeit

Oxygen Atmos ist für **Windows** und **macOS** verfügbar.

## Systemanforderungen

| Anforderung | Minimum | Empfohlen |
|---|---|---|
| **OS** | Windows 10 oder macOS | Windows 11 oder die aktuelle macOS-Version |
| **RAM** | 4 GB | 8 GB+ |
| **Speicher** | 2 GB freier Speicher | SSD mit 10 GB+ |
| **CPU** | Dual-core | Quad-core+ |

## Download

Die wichtigste Download-Quelle ist die Oxygen-Website. Dieselben Installer-Links sind auch im Telegram-Bot verfügbar.

<Steps>
  <Step title="Installer herunterladen">
    Öffnen Sie die [Download-Seite](https://wallet.oxygen.tools/en/download) und laden Sie den Installer für Ihr Betriebssystem herunter.
  </Step>
  <Step title="Alternative: Telegram-Bot">
    Sie können auch den [Telegram-Bot](https://t.me/OduLandBot?start=r_oxygen_x) öffnen, `/start` senden, **💎 Oxygen.Atmos** wählen und die Links **Windows | MacOS** verwenden.
  </Step>
  <Step title="Installer starten">
    Öffnen Sie den heruntergeladenen Installer und folgen Sie den Anweisungen auf dem Bildschirm.
  </Step>
  <Step title="App öffnen">
    Starten Sie Oxygen Atmos, um die Ersteinrichtung zu beginnen.
  </Step>
</Steps>

## Zugriff über Telegram

Zugriff auf Oxygen Atmos, Abo-Status und API key werden über den [Telegram-Bot](https://t.me/OduLandBot?start=r_oxygen_x) verwaltet.

<Note>
  Die Oberfläche des Telegram-Bots ist derzeit auf Russisch. Die Button-Namen unten sind genau so angegeben, wie sie im Bot erscheinen.
</Note>

<Steps>
  <Step title="Bot öffnen">
    Öffnen Sie den [Telegram-Bot](https://t.me/OduLandBot?start=r_oxygen_x) und senden Sie `/start`.
  </Step>
  <Step title="Oxygen Atmos öffnen">
    Wählen Sie im Hauptmenü **💎 Oxygen.Atmos**.
  </Step>
  <Step title="Zugriff wählen">
    Sie können mit dem kostenlosen Plan starten. Er enthält **10 Browserprofile**. Einen kostenpflichtigen Plan wählen Sie im Bot nur dann, wenn Sie ein höheres Profillimit brauchen.
  </Step>
  <Step title="API key kopieren">
    Kopieren Sie den **Персональный API ключ** im Abschnitt Oxygen.Atmos. Sie benötigen ihn beim ersten Start der App.
  </Step>
</Steps>

## Ersteinrichtung

Beim ersten Start von Oxygen Atmos durchlaufen Sie zwei Schritte:

<Steps>
  <Step title="API key eingeben">
    Fügen Sie den API key aus dem [Telegram-Bot](https://t.me/OduLandBot?start=r_oxygen_x) ein. Dadurch wird die App aktiviert.

    <Frame><img src="/images/atmos_ui/onboarding/atmos_first_time_setup_1.png" alt="First time setup — API key entry" /></Frame>
  </Step>
  <Step title="Master password setzen">
    Erstellen Sie ein master password, um sensible lokale Daten zu verschlüsseln: private keys, API keys und Einstellungen. **Continue without encryption** ist möglich, wird aber nicht empfohlen.
  </Step>
</Steps>

<Info>
  Daten werden lokal gespeichert. Oxygen Atmos sendet Ihre Keys oder Zugangsdaten nicht an externe Server.
</Info>

## Auto-updates

Wenn eine neue Version verfügbar ist, erscheint eine Benachrichtigung in der App. Starten Sie Oxygen Atmos neu, um zu aktualisieren.

## App-Daten bei gesperrtem Vault zurücksetzen

Oxygen Atmos speichert Ihr master password nicht und kann es nicht wiederherstellen. Wenn der Vault gesperrt ist und Sie ihn weder mit master password noch PIN öffnen können, klicken Sie auf **Forgot password?** und anschließend auf **reset the app**.

<Frame><img src="/images/atmos_ui/onboarding/atmos_login_reset_flow.png" alt="Gesperrter Vault mit Option zum Zurücksetzen der App" /></Frame>

<Warning>Das Zurücksetzen löscht alle Daten, die Sie auf diesem Gerät zu Oxygen Atmos hinzugefügt haben. Wenden Sie sich im Zweifel zuerst an den Support. Ein zuvor exportiertes Backup können Sie nach der erneuten Einrichtung importieren.</Warning>
