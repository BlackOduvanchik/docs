## Verfügbarkeit

Oxygen Atmos ist für **Windows** und **macOS** verfügbar.

## Systemanforderungen

| Anforderung | Minimum | Empfohlen |
|---|---|---|
| **OS** | Windows 10 oder macOS | Windows 11 oder die aktuelle macOS-Version |
| **RAM** | 4 GB | 8 GB+ |
| **Speicher** | 2 GB freier Speicher | SSD mit 10 GB+ |
| **CPU** | Dual-core | Quad-core+ |

## Download

<Steps>
  <Step title="Installer herunterladen">
    Gehen Sie zu [wallet.oxygen.tools/en/download](https://wallet.oxygen.tools/en/download) und laden Sie den Installer für Ihr Betriebssystem herunter.
  </Step>
  <Step title="Installer starten">
    Öffnen Sie den heruntergeladenen Installer und folgen Sie den Anweisungen auf dem Bildschirm.
  </Step>
  <Step title="App öffnen">
    Starten Sie Oxygen Atmos, um die Ersteinrichtung zu beginnen.
  </Step>
</Steps>

## Ersteinrichtung

Beim ersten Start von Oxygen Atmos durchlaufen Sie zwei Schritte:

<Steps>
  <Step title="API key eingeben">
    Fügen Sie den API key aus Ihrem Konto auf [wallet.oxygen.tools](https://wallet.oxygen.tools) ein. Dadurch wird die App aktiviert.

    <Frame><img src="/images/atmos_ui/onboarding/atmos_first_time_setup_1.png" alt="First time setup — API key entry" /></Frame>
  </Step>
  <Step title="Master password setzen">
    Erstellen Sie ein master password, um sensible lokale Daten zu verschlüsseln: private keys, API keys und Einstellungen. **Continue without encryption** ist möglich, wird aber nicht empfohlen.
  </Step>
</Steps>

<Info>
  Daten werden lokal gespeichert. Oxygen Atmos sendet Ihre Keys oder Zugangsdaten nicht an externe Server.
</Info>

## Auto-updates

Wenn eine neue Version verfügbar ist, erscheint eine Benachrichtigung in der App. Starten Sie Oxygen Atmos neu, um zu aktualisieren.
