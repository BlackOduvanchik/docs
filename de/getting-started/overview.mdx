## Willkommen bei Oxygen Atmos

Oxygen Atmos ist eine Desktop-App, die einen Chromium-basierten Antidetect-Browser mit vollständigem Web3-Wallet-Management verbindet. Jedes Browserprofil arbeitet als isolierte Umgebung mit eigenem digitalen Fingerprint. Die integrierten Module helfen beim Verwalten von Wallets, Exchange-Accounts und Crypto-Transfers in großer Stückzahl.

## Erste Schritte

<Steps>
  <Step title="App herunterladen">
    [Laden Sie Oxygen Atmos herunter und installieren Sie es](/de/getting-started/installation).
  </Step>
  <Step title="Zugriff in Telegram holen">
    Öffnen Sie den [Telegram-Bot](https://t.me/OduLandBot?start=r_oxygen_x), senden Sie `/start`, wählen Sie **💎 Oxygen.Atmos** und kopieren Sie Ihren API key.
  </Step>
  <Step title="Ersteinrichtung durchführen">
    Geben Sie Ihren API key ein und setzen Sie ein master password, um lokale Daten zu schützen.
  </Step>
  <Step title="Profil erstellen">
    Richten Sie Ihr erstes [Browserprofil](/de/browser-profiles/about-profiles) mit eigenem Fingerprint ein.
  </Step>
</Steps>

## Warum Oxygen Atmos

<CardGroup cols={3}>
  <Card title="Überarbeitetes Chromium-Core" icon="fingerprint">
    Das Browser-Core ist auf kontrollierbare Fingerprint-Parameter ausgelegt, einschließlich Signalen auf Geräteebene.
  </Card>
  <Card title="Browser + Wallets" icon="wallet">
    Profile werden beim Erstellen mit Wallets verknüpft. Browser-Identität und On-chain-Aktivität bleiben an einem Ort.
  </Card>
  <Card title="Local-first Security" icon="lock">
    Private keys, API keys und Einstellungen werden verschlüsselt und lokal auf Ihrem Gerät gespeichert.
  </Card>
</CardGroup>

## Anwendungsfälle

| Anwendungsfall | Beschreibung |
|---|---|
| **Airdrop farming** | 50-500+ Wallets mit isolierten Profilen, Proxies und gespeicherten Sessions verwalten |
| **DeFi und Trading** | Separate Profile für DEXs, Lending, Perps und Bridges — jeweils mit eigenem Wallet, Proxy und Session |
| **Wallet management** | Aktivitäten über Wallets, verknüpfte Browserprofile, Tags und Notes verfolgen |
| **Team operations** | Farming im Team mit PIN-Schutz, Tags und geordneten Gruppen koordinieren |
