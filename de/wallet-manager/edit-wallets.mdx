## Einzelnes Wallet bearbeiten

<Steps>
  <Step title="Wallet manager öffnen">
    Öffnen Sie **Wallet manager**.
  </Step>
  <Step title="Wallet auswählen">
    Suchen Sie die gewünschte address oder den alias in der Tabelle.
  </Step>
  <Step title="Bearbeitung öffnen">
    Klicken Sie auf die Bearbeitungsaktion in der Wallet-Zeile.
  </Step>
  <Step title="Felder aktualisieren">
    Ändern Sie alias, tags oder withdrawal address.
  </Step>
  <Step title="Speichern">
    Bestätigen Sie die Änderungen.
  </Step>
</Steps>

## Mehrere Wallets bearbeiten

Um withdrawal address oder alias für mehrere Wallets zu aktualisieren, importieren Sie sie mit aktualisierten Daten erneut über eine der [Importmethoden](/de/wallet-manager/import-wallets).

Wenn die address bereits existiert, aktualisiert Oxygen Atmos die Felder, ohne ein Duplikat zu erstellen.

## Verknüpfte Profile

Wenn ein Wallet in einem Browserprofil verwendet wird, lösen Änderungen an alias oder tags die Verknüpfung nicht. Das Löschen eines Wallets kann Profile betreffen, in denen es als main wallet oder additional wallet verwendet wird.
