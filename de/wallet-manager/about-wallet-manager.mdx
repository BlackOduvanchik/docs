## Überblick

Der Wallet manager ist die zentrale Stelle für EVM-Wallets in Oxygen Atmos. Hier importieren Sie Wallets, vergeben Tags, setzen withdrawal addresses, verfolgen Balances und verknüpfen Wallets mit Browserprofilen.

<Frame><img src="/images/atmos_ui/wallets/atmos_wallets_manager_v040.png" alt="Wallet Manager" /></Frame>

## Tabelle

| Spalte | Beschreibung |
|---|---|
| **Address** | EVM address des Wallets |
| **Alias** | Kurzer Name für Suche und Organisation |
| **Tags** | Gruppen und Labels des Wallets |
| **Withdrawal address** | Standardzieladresse für Transfers |
| **Browser profile** | Verknüpftes Browserprofil, falls vorhanden |
| **Balances** | Gefundene Tokens und Beträge |

## Lokale Speicherung

Importierte Wallets speichern ihre Daten lokal auf Ihrem Gerät. Sensible Daten wie private keys, API keys und Einstellungen werden verschlüsselt und nicht an externe Server gesendet.

## Wichtige Aktionen

- einzelnes Wallet, Liste oder Datei importieren
- alias, tags oder withdrawal address ändern
- Balances in unterstützten Networks prüfen
- Wallets nach Tags, Balances oder verknüpften Profilen filtern
- Wallets in [Browserprofilen](/de/browser-profiles/about-profiles) verwenden
- Wallets in [Transfers](/de/transfers/about-transfers) verwenden
