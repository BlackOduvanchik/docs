## Überblick

Filter helfen beim Arbeiten mit großen Wallet-Listen. Kombinieren Sie Suche, Tags, Networks und Balance-Optionen, um nur die passenden Einträge anzuzeigen.

## Verfügbare Filter

| Filter | Beschreibung |
|---|---|
| **Search** | Suche nach address oder alias |
| **Tags** | Wallets mit ausgewählten Tags anzeigen |
| **Networks** | Wallets mit Aktivität in bestimmten Networks anzeigen |
| **Tokens** | Nach token balances filtern |
| **Browser profile** | Wallets mit oder ohne verknüpftes Profil anzeigen |
| **Show maximum number of protocols** | Anzahl der Protokolle pro Wallet begrenzen |

## Nach Tags filtern

<Steps>
  <Step title="Tags öffnen">
    Klicken Sie oberhalb der Wallet-Tabelle auf **Tags**.
  </Step>
  <Step title="Tags auswählen">
    Wählen Sie einen oder mehrere Tags. Die Tabelle zeigt nur passende Wallets.
  </Step>
  <Step title="Filter zurücksetzen">
    Klicken Sie auf **Reset**, um die komplette Liste wieder anzuzeigen.
  </Step>
</Steps>

## Tipps

- Verwenden Sie Tags für Campaigns, Networks oder Aktivitätstypen
- Kombinieren Sie Search und Tags, um ein bestimmtes Wallet schnell zu finden
- Prüfen Sie das linked browser profile, bevor Sie ein Wallet löschen
