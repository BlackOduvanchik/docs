## Übersicht

Öffnen Sie **Browser → Bookmarks manager**, um Lesezeichen für Oxidium-Profile zu verwalten.

<Frame><img src="/images/atmos_ui/browser/atmos_browser_bookmarks_manager.png" alt="Bookmarks Manager mit Dialog zum Hinzufügen" /></Frame>

Ein globales Lesezeichen wird allen Profilen hinzugefügt. Ein Tag-basiertes Lesezeichen wird nur Profilen hinzugefügt, die mindestens einen ausgewählten Tag haben.

## Ein Lesezeichen hinzufügen

1. Klicken Sie auf **Add bookmark** und wählen Sie **Single**.
2. Geben Sie Name und URL ein.
3. Wählen Sie Profil-Tags oder aktivieren Sie **Make bookmark global**.
4. Klicken Sie auf **Add**.

## Mehrere Lesezeichen hinzufügen

Wählen Sie **Multiple** und geben Sie pro Zeile ein Lesezeichen in diesem Format ein:

```text
URL|title
```

Zum Beispiel:

```text
https://example.com|Example
https://github.com|GitHub
```

Wählen Sie Tags oder die globale Zuweisung und klicken Sie auf **Add**. Filtern Sie die Liste mit **Search**, **Tags** und **Global**.
