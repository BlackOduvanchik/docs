## Überblick

Secure notes sind private Notizen, die an ein Browserprofil angehängt sind. Nutzen Sie sie für Informationen, die beim Profil bleiben sollen: Workflow-Details, Account-Erinnerungen oder operativer Kontext.

Secure notes bleiben in Oxygen Atmos. Sie werden nicht in Websites injiziert und nicht an den gestarteten Browser weitergegeben.

## Speicherung

Secure notes werden lokal gespeichert und verschlüsselt.

## Notizen bearbeiten

Sie können Notizen bearbeiten über:

- den Dialog zum Erstellen oder Bearbeiten eines Profils
- die secure notes Aktion in der Profiltabelle

## Beispiele

| Anwendungsfall | Beispielnotiz |
|---|---|
| **Workflow-Kontext** | `Warmup completed — ready for marketplace flow` |
| **Campaign tracking** | `Lighter Regional Competition — started 2026-01-15` |
| **Status** | `Proxy changed on 2026-02-01` |
| **Anweisung** | `Keep this profile on the current browser version` |
