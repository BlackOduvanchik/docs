## Übersicht

Öffnen Sie **Browser → Global settings**, um Standardwerte für neue Profile festzulegen. Diese Werte können pro Profil überschrieben werden.

## Start-Tabs

| Modus | Verhalten |
|---|---|
| **New** | Einen neuen Tab öffnen |
| **Session** | Tabs der gespeicherten Sitzung wiederherstellen |
| **List** | Eine konfigurierte URL-Liste öffnen |

## WebRTC und UDP-Schutz

**Block unproxied UDP** erlaubt UDP nur, wenn Atmos den Traffic über den Profil-Proxy senden kann.

- UDP-fähige Proxies übertragen WebRTC, QUIC und HTTP/3.
- Kann UDP nicht proxied werden, blockiert Atmos den Traffic.
- Eine direkte UDP-Verbindung kann den Profil-Proxy nicht umgehen und die echte IP nicht offenlegen.
- Proxies ohne UDP funktionieren weiterhin für TCP-Traffic.

<Warning>**Public Interface** kann Informationen der direkten Netzwerkschnittstelle offenlegen.</Warning>
