## Main

Öffnen Sie **Settings**. Unter **Main** finden Sie API Key, Master Password, PIN code, Language, Export files und Import files.

<Frame><img src="/images/atmos_ui/settings/atmos_settings_main_v040.png" alt="Settings Main" /></Frame>

Exportieren Sie Wallets, Accounts oder Software settings als ZIP. Aktivieren Sie **Set encryption password**, um das Archiv zu schützen. Importdateien werden lokal verarbeitet und nicht auf einen Server hochgeladen.

## Connection

<Frame><img src="/images/atmos_ui/settings/atmos_settings_connection.png" alt="Settings Connection" /></Frame>

Wählen Sie **System proxy** oder **Custom proxy**. Das Routing kann separat für Oxygen API, Wallet RPC, Portfolio data und CEX accounts festgelegt werden. Ein Proxy des Wallets, verknüpften Profils oder Exchange Accounts hat Vorrang, wenn er konfiguriert ist.

<Note>Browser profiles verwenden immer den im Profil gespeicherten Proxy. Connection ändert diesen Traffic nicht.</Note>
